# HappyOrNot Customer API v2

> HappyOrNot is a customer-experience feedback platform (the Smiley Terminal / Smiley Touch / Smiley Digital devices). The read-only Customer API v2 lets applications pull button, follow-up, text, demographics, contact-detail and metadata feedback plus the surveys, questions, experience points, alerts, users and smileys that produce it. Authentication is a package-scoped API token (X-HON-API-Token header or auth query param). Responses are JSON or CSV, paged with offset/limit and an X-More-Available header.

## APIs
- [HappyOrNot Customer API v2](https://api.happy-or-not.com/v2/): Read-only feedback and metadata API. Base URL https://api.happy-or-not.com/v2/
